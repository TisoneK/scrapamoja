## Methodology Note

Bash-grep pattern batteries proved unreliable for quoting-heavy regexes on this machine (the first battery missed the URL-embedded credentials because of shell-quoting holes); the reliable pass was a Python driver over `git ls-files` (current tree) and `git cat-file --batch` over `git cat-file --batch-all-objects` (all 5,930 blobs incl. unreachable), printing masked excerpts only — no secret values ever echoed to chat or logs.
