## What shipped

- **`BETB2B_STORE_MODE`** (`store.py:store_mode()` + `init_db`):
  - `auto` / unset — historical behaviour, byte-identical (DATABASE_URL decides).
  - `local` — pure local SQLite; `DATABASE_URL` ignored and never contacted.
  - `mirror` — the known-down-provider mode: `store_fallback.force_active()`
    engages mirror + outbox from the FIRST write (no doomed connect attempt
    per pass); the existing probe/drain cycle replays into the primary
    automatically once reachable. The pause-window recommendation.
  - `remote` — fail fast without `DATABASE_URL` (guards deploys).
  - Unrecognised values raise — a typo'd switch must not silently pick a
    data destination.
- **`store_fallback.force_active()`** — new public activation entry point;
  raises on broken contracts (no `DATABASE_URL` to replay into, or
  `BETB2B_FALLBACK=0`).
- **Tests** — `test_betb2b_store_mode.py`, 9 cases incl. mirror queue-then-
  drain lifecycle against a simulated down/returning primary.
- **Docs** — RAILWAY.md "Running on a local machine — BETB2B_STORE_MODE"
  section with the PowerShell recipe + cross-restart replay caveat.
- **Flake fix** — `test_probe_throttle_blocks_hammering` failed on this box:
  it stamped `_last_probe_at = 0.0` and assumed monotonic uptime > 9999 s
  (~2.8 h) made that read as "long ago". Now stamps `monotonic() - 1e9`.
  (Fails on any freshly-booted machine regardless of product code — verified
  against the stashed tree.)

## Traps worth knowing

- `gates.conf` gate commands hardcode the POSIX venv path `.venv/bin/python`;
  on Lameck-Windows the interpreter is `.venv/Scripts/python.exe`, so every
  configured pytest gate fails and sessions must run the equivalent manually
  (already noted in the inefficiencies log; candidate for a gates portability
  improvement upstream).
- Supabase "insufficient activity" pausing is orthogonal to our fallback
  design: paused ≠ restricted — connects fail outright instead of 25006;
  `store_fallback.classify_failure` covers both (connection-class reasons).
